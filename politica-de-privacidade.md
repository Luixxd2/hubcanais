# Política de Privacidade — HUB Canais

Última atualização: 07/10/2026

## 1. Quem usa
O HUB Canais é uma ferramenta de uso pessoal. Quem a usa é o próprio criador dos canais.

## 2. Quais dados são acessados
Com a autorização do criador, o aplicativo acessa a conta do YouTube dele apenas para enviar vídeos e definir título, descrição e miniatura nos canais que ele administra.

## 3. Como os dados são usados
Os dados são usados somente para essa finalidade. Não vendemos, não compartilhamos e não transferimos dados a terceiros.

## 4. Onde ficam guardados
As credenciais de acesso ficam armazenadas apenas no computador do criador, protegidas pelo sistema do Windows. Nenhum dado é enviado a servidores do aplicativo.

## 5. Como revogar o acesso
O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions, ou apagando a conexão dentro do aplicativo.

## 6. Uso dos dados do Google
O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
